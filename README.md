# 何志勇是你的好市長嗎？（競選宣傳測驗）

單一網頁檔 `index.html`，不需要伺服器或資料庫，可直接放在任何靜態網站空間（GitHub Pages、Netlify、Cloudflare Pages、既有競選網站的子目錄）。

## 內容
- 十個新竹生活情境題，每題四個做法可複選：兩個是何志勇白皮書的主張，兩個不是，選項順序隨機。
- 每題依所選做法中屬於何志勇主張的比例計分（全選何志勇的做法得 1 分、各半得 0.5 分），再平均成百分比；全選四項只會得 0.5 分，無法靠全選拿高分。
- 結果頁顯示「你心目中的好市長類型」（建設、照顧、改革、穩健四型）與「和何志勇想法一致的百分比」，分成一致、部分一致、想法不同三組，並逐題列出何志勇的主張。
- 不收集、不上傳任何作答內容。
