# 新竹市民性格測驗

十個新竹市政情境題（每題四個做法），產生受測者的城市性格與三位新竹市長參選人的政見貼合度，最後邀請受測者填寫四題不記名選舉問卷。

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `public/index.html` | 測驗網頁（單一檔案） |
| `server.js` | 伺服器：提供網頁、儲存結果與問卷、管理匯出。只用 Node.js 內建模組，不需安裝套件 |
| `data/baseline.json` | 1,000 筆隨機模擬的性格分布，僅供後台性格統計參考，不用於畫面上的參選人比例 |
| `Dockerfile` | 容器部署用 |

執行後，真實資料會存在 `data/results.json`（性格類型）與 `data/surveys.json`（問卷），不記錄姓名、聯絡方式或 IP。

## 部署方式

### 方式一：直接用 Node.js（需 Node.js 18 以上）

```bash
ADMIN_TOKEN=請換成一組長隨機字串 PORT=3000 node server.js
```

開啟 `http://伺服器位址:3000` 即可。正式上線請放在 Nginx 或 Caddy 後面並啟用 HTTPS。

### 方式二：Docker

```bash
docker build -t hsinchu-quiz .
docker run -d -p 3000:3000 -e ADMIN_TOKEN=請換成一組長隨機字串 -v hsinchu-quiz-data:/data hsinchu-quiz
```

資料存在 `hsinchu-quiz-data` volume，重建容器不會遺失。

### 方式三：雲端平台（Render、Zeabur、Railway、Fly.io 等）

上傳整個資料夾或連結 Git repo，啟動指令設為 `node server.js`，並設定環境變數。**務必掛載永久磁碟**並把 `DATA_DIR` 指向它，否則平台重啟時資料會消失。

## 環境變數

| 變數 | 預設 | 說明 |
|---|---|---|
| `PORT` | `3000` | 監聽埠 |
| `ADMIN_TOKEN` | （空） | 管理匯出密碼；未設定則匯出功能停用 |
| `DATA_DIR` | `./data` | 資料存放目錄 |
| `USE_BASELINE` | `1` | 設為 `0` 則不使用模擬基準資料，比例只依真實受測者計算 |

## 查看結果（僅限管理者）

- 統計摘要：`https://網址/api/admin/summary?token=您的ADMIN_TOKEN`
- 問卷明細（Excel 可直接開啟的 CSV）：`https://網址/api/admin/surveys.csv?token=您的ADMIN_TOKEN`

管理介面只統計真實填答，不含模擬基準資料。請勿將含 token 的網址分享出去。

## 使用前請注意

1. **民調發布限制**：依《公職人員選舉罷免法》第 53 條，投票日前十日起至投票截止前，不得發布或報導有關候選人或選舉之民意調查資料；其他期間發布民調亦應依規定載明相關事項。本問卷為網路自願填答，樣本不具代表性，不宜作為民調對外發布。
2. **模擬資料**：`baseline.json` 是隨機產生的性格分布，網頁上已註明。它不含任何問卷答案，也不影響管理介面的統計。真實樣本累積足夠後，建議設定 `USE_BASELINE=0`。
3. **重複填答**：每位受測者以瀏覽器內的匿名代碼識別，同一瀏覽器重填會覆蓋舊答案；換瀏覽器或清除資料即可重填，無法完全防止灌票。
4. **政見資料與計分規則**：依 2026 年 6–11 月新聞報導、參選人競選網站與政見彙整網站整理；何志勇部分另依其陣營提供之市政策白皮書《志慧新創，勇敢竹夢》。每題依參選人列為核心的主張對應兩個做法，找不到明確主張或只對應得到一個做法的題目不計分；以隨機作答模擬，三位參選人的平均貼合度皆約 50%。正式使用前，建議再對照各陣營最新政見文宣。
5. **中立性**：參選人依姓氏筆畫排列；頁面附逐題對照與資料來源，供受測者自行查核。
6. **玩家比例**：結果頁「目前已有 O% 玩家政見與他相同」只計算真實玩家，滿 30 人才顯示（門檻可在 `public/index.html` 的 `MIN_PLAYERS` 調整）。此比例不使用模擬資料，避免以虛構數字影響受測者對參選人的觀感。
